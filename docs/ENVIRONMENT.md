# Environment inventory

Real secrets belong in the deployment secret store, never in examples or source control. Build-time
variables require a rebuild; runtime variables require a process restart.

| Variable                                                                                               | Owner / phase           | Required            | Secret             | Validation / safe example                                                      |
| ------------------------------------------------------------------------------------------------------ | ----------------------- | ------------------- | ------------------ | ------------------------------------------------------------------------------ |
| `NODE_ENV`                                                                                             | API/web runtime         | all                 | no                 | `development`, `test`, or `production`                                         |
| `PORT`, `HOST`                                                                                         | API runtime             | optional            | no                 | port number / bind address                                                     |
| `DATABASE_URL`                                                                                         | API, worker, migrations | all DB operations   | yes                | explicit PostgreSQL URL; no implicit fallback                                  |
| `TEST_DATABASE_URL`                                                                                    | integration tests       | integration CI      | yes                | dedicated disposable PostgreSQL database only                                  |
| `REDIS_URL`                                                                                            | API/worker runtime      | all queue operation | yes                | explicit Redis URL; production requires password                               |
| `PG_POOL_MAX`                                                                                          | API runtime             | optional            | no                 | integer 1–100                                                                  |
| `PG_IDLE_TIMEOUT_MS`                                                                                   | API runtime             | optional            | no                 | 1,000–300,000 ms                                                               |
| `PG_CONNECT_TIMEOUT_MS`                                                                                | API runtime             | optional            | no                 | 250–30,000 ms                                                                  |
| `PG_STATEMENT_TIMEOUT_MS`                                                                              | API runtime             | optional            | no                 | 250–120,000 ms                                                                 |
| `PG_SSL_MODE`                                                                                          | API/worker runtime      | optional            | no                 | `disable` or `verify-full`                                                     |
| `READINESS_TIMEOUT_MS`                                                                                 | API/worker runtime      | optional            | no                 | 100–10,000 ms                                                                  |
| `JWT_SECRET`                                                                                           | API runtime             | all                 | yes                | 16+ chars; production requires 32+ non-placeholder chars                       |
| `JWT_ACCESS_TOKEN_TTL`, `JWT_REFRESH_TOKEN_TTL`, `JWT_REMEMBER_REFRESH_TOKEN_TTL`               | API runtime             | optional            | no                 | positive seconds; refresh defaults 24h, remembered 7 days                         |
| `ADMIN_JWT_ACCESS_TOKEN_TTL`, `ADMIN_JWT_REFRESH_TOKEN_TTL`, `ADMIN_JWT_REMEMBER_REFRESH_TOKEN_TTL` | API runtime           | optional            | no                 | positive seconds; refresh defaults 24h, remembered 7 days                        |
| `OTP_EXPIRY_SECONDS`, `OTP_MAX_ATTEMPTS`, `OTP_RESEND_COOLDOWN_SECONDS`                                | API runtime             | optional            | no                 | bounded positive integers                                                      |
| `ONBOARDING_SESSION_TTL_SECONDS`                                                                         | API runtime             | optional            | no                 | positive seconds; onboarding session default 7 days                             |
| `CORS_ORIGINS`                                                                                         | API runtime             | optional            | no                 | comma-separated exact origins                                                  |
| `TRUSTED_PROXY_CIDRS`                                                                                  | API runtime             | proxy deployments   | security-sensitive | comma-separated IP/CIDR; no catch-all                                          |
| `LOG_LEVEL`                                                                                            | API runtime             | optional            | no                 | production must not use `debug`                                                |
| `OTP_PROVIDER`, `PAYMENT_GATEWAY_PROVIDER`                                                             | API runtime             | all                 | no                 | console/mock are development-only; production blocks until real adapters exist |
| `SERVICE_ROLE`                                                                                         | API/worker runtime      | all                 | no                 | `api` or `worker`                                                              |
| `AUTH_SESSION_RETENTION_DAYS`                                                                          | API runtime             | optional            | privacy-sensitive  | integer >= 1                                                                   |
| `QUEUE_REQUIRED`, `SEED_DEMO_DATA`                                                                     | API/bootstrap runtime   | optional            | no                 | `true`/`false`; production forbids demo seed                                   |
| `NEXT_PUBLIC_API_BASE_URL`                                                                             | web build/browser       | production          | public             | absolute HTTPS URL (loopback allowed locally)                                  |
| `API_INTERNAL_BASE_URL`                                                                                | web server runtime      | production Compose  | no                 | internal absolute API URL                                                      |
| `NEXT_DEPLOYMENT_ID`                                                                                   | web build               | production          | no                 | immutable 7–128 character release ID                                           |
| `NEXT_SERVER_ACTIONS_ENCRYPTION_KEY`                                                                   | web build secret        | production          | yes                | base64 AES key, 16/24/32 decoded bytes                                         |
| `E2E_WEB_PORT`, `E2E_API_PORT`, `E2E_BASE_URL`, `E2E_BROWSER_CHANNEL`, `E2E_REUSE_SERVER`, `E2E_VIDEO` | Playwright              | optional            | no                 | isolated test ports, URL, browser, reuse, and video controls                   |
| `CI`                                                                                                   | test runners            | CI only             | no                 | runner-provided truthy flag controlling retries, workers, and strictness       |
| `PERFORMANCE_BASE_URL`, `PERFORMANCE_BROWSER_CHANNEL`, `PERFORMANCE_BROWSER_EXECUTABLE_PATH`           | browser performance     | optional            | no                 | audited URL and installed Chrome/Chromium selection                            |

Compose additionally consumes `POSTGRES_PASSWORD` and `REDIS_PASSWORD` from its secret source.
Changing any API variable requires restarting API and worker. Changing public web or deployment
variables requires rebuilding the single promoted web image. Database tooling fails before making
changes when `DATABASE_URL` is absent.
